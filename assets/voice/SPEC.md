# 関西弁ボイスパック仕様

Datathon Japan 2026 / team03 のアプリ用音声パック。
ICUで抜管した患者について「5分後に再挿管・死亡に至らない確率（＝抜管成功確率）」を算出するアプリで、確率の状態変化を関西弁の音声で知らせるためのもの。真面目な指標を、あえて関西弁のツッコミ口調で返すのが狙い。

- 音声：Muse の声（TTS生成、WAV / PCM 16bit / mono / 24kHz）
- 収録：確定7ファイル（本仕様の表が正）

## 使いどころ（状態 → 音声）

| 状態 | ファイル | セリフ | 発火条件 |
|---|---|---|---|
| 計算不可 | `unknown.wav` | 知らんけど | 必須項目が不足していて確率を計算できない時。計算結果ではなく「出せない」こと自体を伝える |
| 処理中 | `loading.wav` | ちょっと待ってなぁ | データ取得・計算の実行中（ローディング表示とセット） |
| 高・安定 | `high_stable.wav` | 抜いたらええんちゃう？ | 成功確率が高水準で、直近の推移がほぼ横ばい（傾き≒0、ばらつき小） |
| 低・安定 | `low_stable.wav` | まだ早いんちゃう？ | 成功確率が低水準で、直近の推移がほぼ横ばい |
| 上昇中 | `rising.wav` | 上向いてきたでー | 直近ウィンドウの傾きが明確にプラスへ転じた時 |
| 下落気味 | `declining.wav` | あー、雲行き怪しいで | 直近ウィンドウの傾きがマイナスに転じた時（危険域に入る前の早期警告） |
| 危険域 | `danger.wav` | あかーーん | 成功確率が危険域まで落ち、その状態に滞留している時 |

## 実装メモ

- 再生は**状態が遷移した瞬間に1回だけ**。同じ状態が続く間は繰り返さない
- 傾きの符号がゼロ付近で反転を繰り返すと音声が連発する（チャタリング）ため、判定にはヒステリシスを持たせ、発火後はクールダウン（目安30秒）を入れる
- ブラウザの自動再生ポリシーにより、ユーザーの初回操作（開始ボタン等）前に音は出ない。アプリ側で最初にボタンを押させる導線が必要
- 上表の「高水準／低水準／危険域」の具体的な閾値は、モデルの出力レンジに合わせて実装側で決める（本仕様では固定しない）
- Streamlit の場合は WAV をそのまま同梱し、状態遷移時に `st.audio(autoplay)` または base64埋め込みの `<audio autoplay>` で再生する
